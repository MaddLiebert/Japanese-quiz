# 日本語学園 · Nihongo Gakuen

Aplikasi belajar bahasa Jepang offline-first untuk pemula — dari kana dasar sampai siap JLPT N5.

## Stack

React 19 + Vite + Tailwind v4 + vite-plugin-pwa.

## Menjalankan

```bash
npm install
npm run dev      # dev server (http://localhost:5173)
npm run build    # build produksi
npm test         # unit test (node --test)
npm run lint     # lint
```
