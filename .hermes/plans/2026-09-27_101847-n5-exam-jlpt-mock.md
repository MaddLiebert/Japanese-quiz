## 3. Architecture / proposed approach

Create a new feature folder `src/features/n5exam/` that mirrors the Death Quiz structure:
a **pure, JSON-free module** `n5exam.js` (blueprint + question builders + scoring + pass/fail),
its unit test, a **session hook** `useN5Exam.js` (section state machine + per-section timer +
answer collection + submit), and a **screen** `N5ExamScreen.jsx` (intro → section runner →
results). Questions come from a **hybrid bank**: types that can be auto-generated from existing
pools are built on the fly (`kanji_reading` ← `kanji.json`, `grammar_form` ← `grammar.json`,
listening task/key-point ← `mondai.json` + real mp3s), while types that need passages/sentences
the repo lacks (orthography, contextual vocab, paraphrase, ★ composition, text grammar, short/mid
reading, info retrieval, verbal expression, quick response) are authored into a new static
`src/data/n5-exam.json`. Scoring pools Vocabulary+Grammar+Reading into one 0–120 section and
Listening into 0–60, applying the official pass rule. We reuse `completeQuiz`, `recordAnswer`,
`AudioPlayer`, `Furigana`, and the neo-brutalist visual language already in the repo.

## 4. Official JLPT N5 facts this feature encodes (research result — authoritative)

Source: `https://www.jlpt.jp/e/guideline/testsections.html` (composition) and
`https://www.jlpt.jp/e/guideline/results.html` (scoring). Times per the Dec-2020 revision.

**Test sections & times (N5):**
1. Language Knowledge (Vocabulary) — **20 min**
2. Language Knowledge (Grammar)・Reading — **40 min**
3. Listening — **30 min**

**Question-type composition for N5 (official, ○ = present at N5):**
- Vocabulary: Kanji reading ○, Orthography ○, Contextually-defined expressions ○, Paraphrases ○
  *(Word formation ✗ and Usage ✗ do not exist at N5)*
- Grammar: Sentential grammar 1 (select grammar form) ○, Sentential grammar 2 (sentence composition ★) ○, Text grammar ○
- Reading: Comprehension short passages ○, Comprehension mid-size passages ○, Information retrieval ○
  *(Long passages ✗, Integrated ✗, Thematic ✗ at N5)*
- Listening: Task-based comprehension ○, Comprehension of key points ○, Verbal expressions ○, Quick response ○
  *(General outline ✗, Integrated ✗ at N5)*

**Scoring (N5):**
- Total score range **0–180**; **overall pass mark 80**.
- Sectional scores: **Language Knowledge (Vocabulary/Grammar)・Reading: 0–120**, sectional pass **38**.
- **Listening: 0–60**, sectional pass **19**.
- Pass requires **total ≥ 80 AND both sectionals ≥ their minimum**. Missing one section = fail.
- Real JLPT uses scaled (IRT) scoring; we approximate with a proportional raw→scaled map (§5.4).

**Approximate question counts per type** (from the official N5 sample papers — used as our blueprint):
Vocab: 漢字読み 7, 表記 5, 文脈規定 6, 言い換え 4 = 22.
Grammar・Reading: 文の文法1 16, 文の文法2 ★ 5, 文章の文法 5, 内容理解(短文) 3, 内容理解(中文) 2, 情報検索 1 = 32.
Listening: 課題理解 7, ポイント理解 6, 発話表現 5, 即時応答 6 = 24. **Total 78 questions / 90 min.**

// Meniru JLPT N5 resmi: 3 seksi berwaktu (20/40/30 mnt), 78 soal, skor 0–180.
// Sumber: jlpt.jp/guideline/testsections.html & /results.html (revisi Des 2020).

// Skor resmi JLPT N5.
export const N5_PASS_TOTAL = 80;      // total lulus
export const N5_PASS_LKR = 38;        // sectional: Vocab+Grammar+Reading
export const N5_PASS_LISTENING = 19;  // sectional: Listening
export const LKR_MAX = 120;           // skor maksimum seksi gabungan A+B
export const LISTENING_MAX = 60;      // skor maksimum seksi Listening

// Blueprint tipe soal (mondai) persis komposisi resmi N5.
// `gen` = bisa dibangun otomatis dari pool yang sudah ada; selain itu dari n5-exam.json.
export const N5_SECTIONS = {
  vocab: {
    minutes: 20,
    label: { id: 'Pengetahuan Bahasa (Kosakata)', en: 'Language Knowledge (Vocabulary)' },
    mondai: [
      { type: 'kanji_reading', count: 7, gen: 'kanji' },
      { type: 'orthography', count: 5 },
      { type: 'context_vocab', count: 6 },
      { type: 'paraphrase', count: 4 },
    ],
  },
  grammarReading: {
    minutes: 40,
    label: { id: 'Pengetahuan Bahasa (Tata Bahasa)・Membaca', en: 'Language Knowledge (Grammar)・Reading' },
    mondai: [
      { type: 'grammar_form', count: 16, gen: 'grammar' },
      { type: 'sentence_composition', count: 5 },
      { type: 'text_grammar', count: 5 },
      { type: 'reading_short', count: 3 },
      { type: 'reading_mid', count: 2 },
      { type: 'info_retrieval', count: 1 },
    ],
  },
  listening: {
    minutes: 30,
    label: { id: 'Menyimak', en: 'Listening' },
    mondai: [
      { type: 'task_comprehension', count: 7, gen: 'mondai' },
      { type: 'key_point', count: 6, gen: 'mondai' },
      { type: 'verbal_expression', count: 5 },
      { type: 'quick_response', count: 6 },
    ],
  },
};

export const N5_SECTION_ORDER = ['vocab', 'grammarReading', 'listening'];
export const N5_TOTAL_MINUTES = N5_SECTION_ORDER.reduce((s, k) => s + N5_SECTIONS[k].minutes, 0);

// Jumlah soal mentah satu seksi.
export const sectionRawTotal = (sectionKey) =>
  N5_SECTIONS[sectionKey].mondai.reduce((s, m) => s + m.count, 0);

// Pemetaan skor: proporsional (aproksimasi IRT asli yang tak bisa direplikasi offline).
export const scaleSection = (rawCorrect, rawTotal, maxScore) =>
  rawTotal <= 0 ? 0 : Math.round((rawCorrect / rawTotal) * maxScore);

// Nilai kelulusan: total ≥80 DAN lkr ≥38 DAN listening ≥19.
export const evaluatePass = ({ lkrRaw, lkrTotal, listeningRaw, listeningTotal }) => {
  const lkrScaled = scaleSection(lkrRaw, lkrTotal, LKR_MAX);
  const listeningScaled = scaleSection(listeningRaw, listeningTotal, LISTENING_MAX);
  const total = lkrScaled + listeningScaled;
  const lkrOk = lkrScaled >= N5_PASS_LKR;
  const listeningOk = listeningScaled >= N5_PASS_LISTENING;
  const totalOk = total >= N5_PASS_TOTAL;
  return {
    lkrScaled, listeningScaled, total,
    lkrOk, listeningOk, totalOk,
    passed: totalOk && lkrOk && listeningOk,
  };
};

export const formatClock = (totalSeconds) => {
  const s = Math.max(0, Math.floor(totalSeconds));
  const mm = String(Math.floor(s / 60)).padStart(2, '0');
  const ss = String(s % 60).padStart(2, '0');
  return `${mm}:${ss}`;
};

```js
// ── Builder soal ────────────────────────────────────────────────────────────
// Item shape seragam (dibaca UI):
// { id, mondai, prompt, promptFurigana?, passage?, audio?, options:[4], correctIndex, answer, explanation }
import { shuffle } from '../quiz/questionBuilder.js';

const pick4 = (correct, pool, rng) => {
  const seen = new Set([correct]);
  const out = [correct];
  const shuffled = shuffle(pool, rng);
  for (const v of shuffled) {
    if (out.length >= 4) break;
    if (seen.has(v)) continue;
    seen.add(v); out.push(v);
  }
  // Fallback bila pool kurang dari 4 nilai unik (mis. kanji bacaan pendek).
  let n = 1;
  while (out.length < 4) { out.push(`—${n}`); n++; }
  return out;
};

const withAnswer = (base, correctValue, distractorPool, rng) => {
  const options = pick4(correctValue, distractorPool, rng);
  const shuffled = shuffle(options, rng);
  return { ...base, options: shuffled, correctIndex: shuffled.indexOf(correctValue), answer: correctValue };
};

// — Tipe yang dibangun otomatis dari pool yang ada —
const GEN = {
  kanji_reading: (datasets, rng) => {
    const pool = datasets.kanji;
    const readings = pool.flatMap(k => k.onyomi.split('、').concat(k.kunyomi.split('、')))
      .map(s => s.trim()).filter(Boolean);
    return pool.map((k, i) => {
      const correct = k.kunyomi.split('、')[0].trim() || k.onyomi.split('、')[0].trim();
      return withAnswer({
        id: `n5_kanji_${k.id}`, mondai: 'kanji_reading',
        prompt: `「${k.char}」の 読み方は どれですか。`,
        explanation: `${k.char}（${k.meaning}）= ${correct}`,
      }, correct, readings, rng);
    });
  },
  grammar_form: (datasets, rng) => {
    const particles = [...new Set(datasets.grammar.map(g => g.char))];
    return datasets.grammar.map(g => {
      const opts = pick4(g.char, particles, rng);
      const shuffled = shuffle(opts, rng);
      return {
        id: `n5_grm_${g.id}`, mondai: 'grammar_form',
        prompt: g.question, options: shuffled, correctIndex: shuffled.indexOf(g.char),
        answer: g.char, explanation: `Jawaban: ${g.char} (${g.romaji})`,
      };
    });
  },
  listening: (datasets, rng) => {
    // mondai.json → opsi teks sudah ada; dipakai untuk task_comprehension & key_point.
    return shuffle(datasets.mondai, rng).map(m => {
      const shuffled = shuffle(m.options.map((t, idx) => ({ t, idx })), rng);
      return {
        id: `n5_lst_${m.id}`, mondai: 'task_comprehension',
        prompt: m.questionText, audio: m.audio, options: shuffled.map(o => o.t),
        correctIndex: shuffled.findIndex(o => o.idx === m.correctIndex),
        answer: m.options[m.correctIndex], explanation: m.explanation, dialogScript: m.dialogScript,
      };
    });
  },
};

export const buildSection = (type, bank, datasets, count, rng = Math.random) => {
  const authored = Array.isArray(bank?.[type]) ? bank[type] : [];
  let source;
  if (type === 'kanji_reading') source = GEN.kanji_reading(datasets, rng);
  else if (type === 'grammar_form') source = GEN.grammar_form(datasets, rng);
  else if (type === 'task_comprehension' || type === 'key_point') source = GEN.listening(datasets, rng);
  else source = authored;

  if (!source || source.length === 0) return [];
  const shuffled = shuffle(source, rng);
  // Ambil `count`; bila bank < count, ulang dari awal (sampling with replacement) — exam tetap penuh.
  const out = [];
  for (let i = 0; i < count; i++) {
    const it = shuffled[i % shuffled.length];
    out.push({ ...it, mondai: type, _slot: i });
  }
  return out;
};

export const buildExam = (bank, datasets, rng = Math.random) =>
  N5_SECTION_ORDER.map(key => {
    const sec = N5_SECTIONS[key];
    const items = sec.mondai.flatMap(m => buildSection(m.type, bank, datasets, m.count, rng));
    return { key, minutes: sec.minutes, label: sec.label, items };
  });

// answers = array boolean sejajar exam.flatMap(s => s.items)
export const scoreExam = (exam, answers) => {
  let cursor = 0;
  const perSection = {};
  const perMondai = [];
  for (const sec of exam) {
    let correct = 0;
    for (const item of sec.items) {
      const ok = !!answers[cursor++];
      if (ok) correct++;
      const row = perMondai.find(r => r.mondai === item.mondai);
      if (row) { row.correct += ok ? 1 : 0; row.total += 1; }
      else perMondai.push({ mondai: item.mondai, correct: ok ? 1 : 0, total: 1 });
    }
    perSection[sec.key] = { correct, total: sec.items.length };
  }
  const lkrRaw = perSection.vocab.correct + perSection.grammarReading.correct;
  const lkrTotal = perSection.vocab.total + perSection.grammarReading.total;
  const verdict = evaluatePass({
    lkrRaw, lkrTotal,
    listeningRaw: perSection.listening.correct, listeningTotal: perSection.listening.total,
  });
  return { perSection, perMondai, lkrRaw, lkrTotal, listeningRaw: perSection.listening.correct, ...verdict };
};
```

### Task 4 — Session hook: `src/features/n5exam/useN5Exam.js`

State machine: `phase: 'intro' | 'section' | 'sectionBreak' | 'results'`. Holds the built exam,
current section index, current question index, per-section countdown, an answers array, and a
per-section lock (once a section's timer hits 0, it auto-submits and moves on — **no going back**,
like the real exam).

Create `src/features/n5exam/useN5Exam.js`:

```js
import { useState, useCallback, useRef, useEffect } from 'react';
import { useItemProgress, useUserStats } from '../progress/ProgressContext';
import { useEffectLayer } from '../effects/EffectContext';
import kanjiData from '../../data/kanji.json';
import grammarData from '../../data/grammar.json';
import kotobaData from '../../data/kotoba.json';
import mondaiData from '../../data/mondai.json';
import hiraganaData from '../../data/hiragana.json';
import katakanaData from '../../data/katakana.json';
import bank from '../../data/n5-exam.json';
import { buildExam, scoreExam, N5_SECTIONS, N5_SECTION_ORDER } from './n5exam.js';

const DATASETS = {
  kanji: kanjiData, grammar: grammarData, kotoba: kotobaData,
  mondai: mondaiData, hiragana: hiraganaData, katakana: katakanaData,
};

const XP_PER_CORRECT = 15; // konsisten dengan MondaiQuiz

export function useN5Exam() {
  const [phase, setPhase] = useState('intro');   // intro → section → sectionBreak → results
  const [exam, setExam] = useState([]);
  const [sectionIndex, setSectionIndex] = useState(0);
  const [qIndex, setQIndex] = useState(0);
  const [selected, setSelected] = useState(null);   // index opsi terpilih (per soal)
  const [isAnswered, setIsAnswered] = useState(false);
  const [timeLeft, setTimeLeft] = useState(null);   // detik seksi berjalan
  const [result, setResult] = useState(null);

  const answersRef = useRef([]);       // boolean per soal, urut global
  const globalCursorRef = useRef(0);   // posisi global saat ini
  const submittedRef = useRef(false);
  const examRef = useRef([]);

  const { recordAnswer } = useItemProgress();
  const { completeQuiz } = useUserStats();
  const { triggerEffect, resetEffectStreak } = useEffectLayer();

  const start = useCallback(() => {
    const built = buildExam(bank, DATASETS);
    examRef.current = built;
    answersRef.current = new Array(built.reduce((s, x) => s + x.items.length, 0)).fill(false);
    globalCursorRef.current = 0;
    submittedRef.current = false;
    resetEffectStreak();
    setExam(built);
    setSectionIndex(0);
    setQIndex(0);
    setSelected(null);
    setIsAnswered(false);
    setTimeLeft(N5_SECTIONS[N5_SECTION_ORDER[0]].minutes * 60);
    setResult(null);
    setPhase('section');
  }, [resetEffectStreak]);

  const currentSection = exam[sectionIndex] || null;
  const currentItem = currentSection ? currentSection.items[qIndex] : null;

  // Timer seksi — berhenti saat di luar fase 'section'.
  useEffect(() => {
    if (phase !== 'section' || timeLeft === null) return;
    if (timeLeft <= 0) return;
    const t = setInterval(() => setTimeLeft(prev => (prev <= 1 ? 0 : prev - 1)), 1000);
    return () => clearInterval(t);
  }, [phase, timeLeft]);

  // Waktu habis → auto-submit seksi ini (soal belum dijawab = salah).
  useEffect(() => {
    if (phase === 'section' && timeLeft === 0 && !submittedRef.current) {
      submittedRef.current = true;
      endSection(true);
    }
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [timeLeft, phase]);

  const chooseOption = useCallback((optIndex) => {
    if (isAnswered || !currentItem) return;
    const correct = optIndex === currentItem.correctIndex;
    answersRef.current[globalCursorRef.current] = correct;
    setSelected(optIndex);
    setIsAnswered(true);
    recordAnswer(currentItem.id, correct, XP_PER_CORRECT);
    triggerEffect(correct ? 'correct' : 'wrong');
  }, [isAnswered, currentItem, recordAnswer, triggerEffect]);

  const nextQuestion = useCallback(() => {
    if (!currentSection) return;
    globalCursorRef.current += 1;
    if (qIndex + 1 < currentSection.items.length) {
      setQIndex(qIndex + 1);
      setSelected(null);
      setIsAnswered(false);
    } else {
      endSection(false);
    }
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [currentSection, qIndex]);

  // Akhiri seksi: maju ke seksi berikutnya (dengan layar jeda) atau ke hasil.
  function endSection(timedOut) {
    submittedRef.current = false;
    if (sectionIndex + 1 < examRef.current.length) {
      setPhase('sectionBreak');
      setSectionIndex(sectionIndex + 1);
      setQIndex(0);
      setSelected(null);
      setIsAnswered(false);
      // waktu seksi berikutnya diset saat lanjut
      setTimeLeft(null);
      setLastTimedOut(timedOut);
    } else {
      finish();
    }
  }

  const [lastTimedOut, setLastTimedOut] = useState(false);

  const continueToNextSection = useCallback(() => {
    const key = N5_SECTION_ORDER[sectionIndex];
    setTimeLeft(N5_SECTIONS[key].minutes * 60);
    setPhase('section');
  }, [sectionIndex]);

  function finish() {
    const scored = scoreExam(examRef.current, answersRef.current);
    const totalQ = answersRef.current.length;
    const correct = answersRef.current.filter(Boolean).length;
    const wrongCount = totalQ - correct;
    completeQuiz(scored.passed, 'hard', 1, wrongCount, totalQ);
    setResult(scored);
    setPhase('results');
  }

  const quit = useCallback(() => {
    submittedRef.current = true;
    setPhase('intro');
    setExam([]);
    setResult(null);
  }, []);

  return {
    phase, exam, currentSection, currentItem, sectionIndex, qIndex,
    selected, isAnswered, timeLeft, result, lastTimedOut,
    start, chooseOption, nextQuestion, continueToNextSection, quit,
  };
}
```

> Note: `endSection` is a plain function used before its declaration inside the component — that's
> fine (function declarations hoist). Keep `lastTimedOut` state declared **before** first use; if
> oxlint flags use-before-declaration, move the `const [lastTimedOut, setLastTimedOut] = useState(false);`
> up with the other `useState` calls at the top.

## 7. Risks, tradeoffs, and open questions

- **Scoring is proportional, not IRT.** Real JLPT uses item-response scaling; offline we map raw
  correct → section max proportionally. Documented in `n5exam.js`. Acceptable for a study mock;
  do **not** present it as the official score.
- **Content authenticity is the main effort.** The repo has no reading passages or 表記/文脈規定
  sentences, so `n5-exam.json` must be authored. Quality of distractors decides whether the exam
  "feels like JLPT". Keep N5-level, 4 plausible options, varied `correctIndex`.
- **Listening reuse.** `task_comprehension`/`key_point` are built from `mondai.json` (real mp3s,
  ~30–60 s each). That audio is choukai-style, not literal JLPT N5 mondai — close, not exact.
  `verbal_expression`/`quick_response` have **no audio**; they are text-only items in the bank
  (acceptable, but a real exam would play them — future work: TTS via `src/utils/audio.js`).
- **No going back between sections** mirrors the real test but is stricter than the app's other
  quizzes; the intro must state it clearly. Voluntary quit = no penalty (like Death Quiz).
- **XP/Medaru:** reuse `recordAnswer` (+15/correct) and `completeQuiz(...)` (which already pays
  +2 Medaru/correct and updates win-rate with `passed`). No new economy action needed (DRY).
- **Open question for the user (ask before/while executing):** should the N5 Exam be gated behind
  a rank (e.g. Sensei ≥15 000 XP) or open to everyone? Plan assumes **open to everyone** (it's the
  natural final exam); change one line in `Home.jsx` if gated.
