# Plan: Fixing Broken Mondai Quiz Data & UI Handling

## Goal
Identify and fix entries in `src/data/mondai.json` that lack valid quiz options, and enhance `src/features/quiz/MondaiQuiz.jsx` to handle broken data gracefully.

## Current context / assumptions
- `src/data/mondai.json` has ~31 entries with placeholder options ("Tidak ada informasi tersebut", "Topik lain", etc.) generated by a faulty automated script.
- The `dialogScript` in these JSON entries contains the actual audio transcripts, which can be used to generate valid questions and options.

## Architecture / proposed approach
- **Immediate Fix:** Create a script to detect and mark "placeholder" questions as "needs_review".
- **Short-term Improvement:** Update `MondaiQuiz.jsx` to skip entries marked `needs_review` or display a "Coming Soon" placeholder instead of showing broken multiple-choice options.
- **Long-term Fix:** Use an LLM tool to re-generate correct options and questions based on the existing `dialogScript` for all 31 broken entries.

## Step-by-step tasks

### Task 1: Audit & Mark Broken Entries
- **File path:** `scripts/audit_mondai.js` (create)
- **Description:** Scan `src/data/mondai.json` for placeholder options and generate a report of `id`s that need re-generation.
- **Command:** `node scripts/audit_mondai.js`

### Task 2: Implement UI Safeguard
- **File path:** `src/features/quiz/MondaiQuiz.jsx`
- **Description:** Add check: if `options` contains "Tidak ada informasi tersebut", do not render the quiz. Display a helpful "Soal dalam perbaikan" component instead.

### Task 3: Re-generate Quiz Data (The Real Fix)
- **Description:** Iterate through the `needs_review` list, extract `dialogScript`, and use an LLM to generate a valid `questionText` + 4 meaningful `options` + `correctIndex`.
- **Note:** This requires LLM access (which Hermes has).

## Risks, tradeoffs, and open questions
- Regenerating 31 entries manually or via LLM is the only way to get actual quiz functionality.
- UI safeguard is trivial, but fixing the *data* is necessary for the feature to be useful.
