# Plan — Gojo Anime Style v3: Cel-Shade + Tinta + Impact (rombak total dari motion-graphics)

Sumber: keluhan user — **"gw gak suka sama style terlalu bukan anime, gw mau kaya anime gitu style nya bukan bola sama partikel biasa"**.

Keputusan clarify: **(1)** pakai SEMUA elemen bahasa anime (outline tinta, impact star, 集中線, screentone); **(2)** "Semua diganti ke bahasa anime (cel-shade + tinta) — paling konsisten"; **(3)** "Gaya anime warna (warna kanon tapi tepi keras + glow anime)".

---

## 1. Goal

Ganti bahasa visual efek Gojo dari **motion-graphics** (gradient halus, blur, glow lembut, bola kaca, partikel titik) menjadi **bahasa anime/manga**: garis tinta tegas (outline), warna rata cel-shade (hard-stop), impact star, 集中線 (speed lines), screentone halftone, dan オノマトペ (teks bunyi). Warna tetap kanon (蒼 biru / 赫 merah / 茈 ungu). Tetap: **efek muncul dari tepi (ao/aka), murasaki tabrakan di tengah**, petir hitam, **senyap (tanpa suara)**.

---

## 2. Diagnosis — kenapa sekarang "bukan anime"

| Sekarang (motion-graphics) | Anime (target) |
|---|---|
| `radial-gradient(... 55%, transparent 82%)` → tepi blur | **Hard-stop** cel-shade: 2–3 bidang warna rata, tepi KERAS |
| `boxShadow: 0 0 36px color` → glow lembut | **Garis tinta**: `0 0 0 3px #0a0a0a` (ring keras, radius blur 0) |
| Asap blur (`gojoSmoke`) | **集中線**: garis tinta keras dari titik fokus |
| Partikel titik/bara gradient | **Serpihan tinta** (hard edge, sudut tegas) |
| Bola kaca glossy | **Bola cel-shade**: band warna rata + highlight keras + outline tinta |
| Tidak ada impact | **Impact star** (bintang ledakan) + **flash frame** + **オノマトペ** |
| Tidak ada shading | **Screentone** (titik halftone) |

Bukti bahasa manga sudah ada di app: `src/index.css` → `.bg-seigaiha`, `.bg-asanoha`, `.bg-ichimatsu` (SVG garis tegas). Efek Gojo akan satu bahasa dengan ini.

```js
// ── Bahasa anime: tinta & flash ────────────────────────────────────────────
export const GOJO_INK = '#0a0a0a';    // outline tinta (ring keras, bukan blur)
export const GOJO_FLASH = '#ffffff';  // flash frame 1-frame

// Titik fokus impact (vw dari tengah): ao kanan, aka kiri, murasaki tengah.
export const gojoImpactFocus = (technique) => {
  if (technique === 'ao') return { xVw: GOJO_EDGE_ANCHOR_VW, yVw: 0 };
  if (technique === 'aka') return { xVw: -GOJO_EDGE_ANCHOR_VW, yVw: 0 };
  return { xVw: 0, yVw: 0 };   // murasaki / domain
};

// Impact star (bintang ledakan anime) — polygon lokal 0..100, pusat 50,50.
export const gojoImpactStar = (seed = 1, rng = Math.random, spikes = 8) => {
  const pts = [];
  const rot = rng() * Math.PI * 2;
  for (let i = 0; i < spikes * 2; i++) {
    const a = rot + (i / (spikes * 2)) * Math.PI * 2;
    const r = i % 2 === 0 ? 46 + rng() * 4 : 16 + rng() * 8;  // spike luar / dalam
    pts.push(`${Math.round(50 + Math.cos(a) * r)},${Math.round(50 + Math.sin(a) * r)}`);
  }
  return { id: `${seed}-star`, spikes, points: pts.join(' ') };
};

// 集中線: garis tinta memancar dari fokus. Untuk ao/aka ujung tetap di band tepi.
export const gojoSpeedLines = (technique, seed = 1, rng = Math.random, count = 14) => {
  const focus = technique === 'ao' ? { x: 82, y: 50 } : technique === 'aka' ? { x: 18, y: 50 } : { x: 50, y: 50 };
  const maxLen = technique === 'murasaki' ? 60 : 24;   // ao/aka pendek → tidak ke tengah
  const out = [];
  for (let i = 0; i < count; i++) {
    const a = rng() * Math.PI * 2;
    const len = maxLen * (0.55 + rng() * 0.45);
    const inner = 6 + rng() * 6;
    const from = [focus.x + Math.cos(a) * inner, focus.y + Math.sin(a) * inner];
    const to = [focus.x + Math.cos(a) * (inner + len), focus.y + Math.sin(a) * (inner + len)];
    out.push({
      id: `${seed}-sl-${i}`,
      from: [clamp100(from[0]), clamp100(from[1])],
      to: [clamp100(to[0]), clamp100(to[1])],
      width: 0.6 + rng() * 1.4,
      delay: rng() * 0.12,
    });
  }
  return out;
};

// Screentone: titik halftone (shading manga) di sekitar fokus.
export const gojoHalftone = (seed = 1, rng = Math.random, count = 18) => {
  const out = [];
  for (let i = 0; i < count; i++) {
    out.push({
      id: `${seed}-ht-${i}`,
      x: 50 + (rng() * 2 - 1) * 40,
      y: 50 + (rng() * 2 - 1) * 40,
      size: 0.6 + rng() * 1.4,
      delay: rng() * 0.2,
    });
  }
  return out;
};

// オノマトペ (teks bunyi anime).
export const gojoOno = (technique) => {
  switch (technique) {
    case 'ao': return 'ドン';
    case 'aka': return 'ゴッ';
    case 'murasaki': return 'ズドン';
    case 'domain': return 'ゴゴゴ';
    case 'domain_zenith': return 'ゴゴゴゴ';
    default: return '';
  }
};
```

## 8. Risks, tradeoffs, open questions

- **Outline tinta di tema gelap**: `#0a0a0a` di atas `#141517` nyaris tak beda. Mitigasi: tiap elemen tinta diberi rim/pasangan warna kanon terang (bola = tinta + warna terang; petir = tinta + rim `#ece6ff`). Kalau kurang, tune `GOJO_INK` jadi `#050505` + tambah outline warna terang.
- **`-webkit-text-stroke`** didukung Chrome/Safari/Firefox modern. Fallback: `text-shadow` keras offset.
- **Banyak elemen** (14 集中線 + 18 halftone + 5 petir + serpihan + star). Semua transform/opacity/pathLength → aman; kalau jank turunkan count.
- **`clamp100`** harus didefinisikan SEBELUM `gojoSpeedLines` (dipakai juga oleh `gojoBolts`) — pastikan urutan deklarasi di file.
- **Open question**: apakah user mau オノマトペ (teks bunyi) atau terasa berisik? Kalau tidak suka, hapus Layer 2e (1 blok).
- **Open question**: ukuran impact star — kalau terlalu besar/kecil, tune `46`/`16` di `gojoImpactStar`.
