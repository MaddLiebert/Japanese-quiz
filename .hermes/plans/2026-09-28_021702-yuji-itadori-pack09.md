## 3. Architecture / proposed approach

Tiga modul baru + satu komponen besar + satu file wiring, mengikuti pembagian yang sudah terbukti di subsistem Gojo: **`yujiFx.js`** = semua logika murni & angka desain (dites `node --test`), **`yujiGifs.js`** = registry GIF + sinkronisasi durasi terukur (dites), **`sfx.js`** = klip teknik deterministik + 10 SFX one-shot (params murni dites), **`YujiBurst.jsx` + `YujiTakeover.jsx`** = render visual saja (baca dari `yujiFx`/`yujiGifs`, tanpa aturan sendiri).

Wiring: `EffectContext.jsx` dapat jalur `activeVisual === 'yuji'` (early-return, tidak menyentuh jalur Hina/Gojo), state baru (`yujiCharge`, `yujiTakeover`, `yujiCombo`, `yujiFinisher`), dan `castTakeover()`. `Practice.jsx` menghitung `burnedIds` (dari `yujiBurnedIds`) sekali per soal, menyembunyikan 2 opsi salah, dan mengirim `xpMultiplier` ke `selectAnswer`/`answerQuestion`. `pack_09.visual` baru diubah `'dummy' → 'yuji'` **di task 8** (setelah komponen & wiring ada) supaya app tidak pernah berada di state setengah jadi.

Alur data satu jawaban (visual `yuji`):
```
Practice.handleKotobaOptionClick
  → triggerEffect('correct'|'wrong')
      → EffectContext.triggerEffect → triggerYuji(type, kind, cfg)
          ├─ pilih teknik: combo (kai/hachi/fuga) ATAU yujiTechniqueFor(kind, streak)
          ├─ suara  : playYujiTechnique(tech) / playWrongSound() / zakome  + SFX one-shot
          ├─ GIF    : yujiGifForAnswer(type, tech, takeover, combo)
          ├─ hold   : yujiAnswerHoldMs(tech, gif, clipMs, cfg.hold)
          ├─ bar    : setYujiCharge(yujiCurseCharge(streak)) (+ tick/chime)
          └─ combo  : naik 1 tiap benar saat takeover; 3 → setYujiFinisher(true)
  → selectAnswer(option.id, { xpMultiplier: finisherOn ? 2 : 1 })
```
`EffectLayer` merender `YujiBurst` (per jawaban), `YujiTakeoverCine` (sekali per cast) + `YujiAura` (persist selama takeover) + `YujiCurseBar` (selama sesi kuis).

  const list = YUJI_GIFS[kind];

  return list[Math.floor(rng() * list.length)];

//   benar combo 開 (combo >= 3) -> fuga · keiteiken/manjigeri -> keiteiken

export const yujiGifForAnswer = (type, technique = null, takeover = false, combo = 0, rng = Math.random) => {
  if (type === 'wrong') return takeover ? pickYujiGif('zakome', rng) : pickYujiGif('wrong', rng);
  if (type !== 'correct') return null;
  if (takeover && combo >= 3) return pickYujiGif('fuga', rng);
  if (technique === 'keiteiken' || technique === 'manjigeri') return pickYujiGif('keiteiken', rng);
  if (technique === 'kokusen') return pickYujiGif('kokusen', rng);
  return null;
};

export const yujiTakeoverGif = (rng = Math.random) => pickYujiGif('takeover', rng);

// Durasi SATU PUTARAN tiap GIF (ms) — hasil ukur PIL (2026-09-28). JANGAN ditebak.
export const YUJI_GIF_MS = {
  '/effects/keiteiken.gif': 1000,
  '/effects/kokusen.gif': 3600,
  '/effects/fuga.gif': 3900,
  '/effects/sukuna transform.gif': 2300,
  '/effects/yuji kuso.gif': 4100,
  '/effects/yuji madada.gif': 3900,
  '/effects/yuji shimata.gif': 5070,

const YUJI_HOLD_MAX = 8000;

// Lama tampil efek: max(hold dasar, 1 putaran GIF), di-clamp <=8s.
export const yujiGifHoldMs = (src, baseHoldMs = 0) => {
  const base = (Number.isFinite(baseHoldMs) && baseHoldMs > 0) ? Math.round(baseHoldMs) : 0;
  const gifMs = (src && Number.isFinite(YUJI_GIF_MS[src])) ? YUJI_GIF_MS[src] : 0;
  return Math.min(YUJI_HOLD_MAX, Math.max(base, gifMs));

// Pelajaran Gojo: efek selesai sebelum suara = "kecepetan" -> klip selalu menang.
export const yujiAnswerHoldMs = (technique, gifSrc, clipMs = 0, baseHoldMs = 0) => {
  const measured = Number.isFinite(YUJI_CLIP_MS[technique]) ? YUJI_CLIP_MS[technique] : 0;
  const clip = (Number.isFinite(clipMs) && clipMs > 0) ? clipMs : measured;
  const want = Math.max(baseHoldMs || 0, clip > 0 ? clip + 400 : 0);
  return yujiGifHoldMs(gifSrc, want);
};

// Semua path GIF (flat, unik) -> preload/predecode.
export const yujiGifPaths = () => {
  const out = [];
  for (const list of Object.values(YUJI_GIFS)) {
    if (Array.isArray(list)) for (const p of list) if (p && !out.includes(p)) out.push(p);
  }
  return out;
};

// Preload + DECODE semua GIF Yuji. Aman dipanggil berulang. loader injectable (tes).
let gifPreloaded = false;
export const preloadYujiGifs = (loader) => {
  const paths = yujiGifPaths();
  if (typeof window === 'undefined' && !loader) return paths.length;
  if (gifPreloaded && !loader) return paths.length;
  gifPreloaded = true;
  const make = loader || (() => new Image());
  for (const p of paths) {
    try {
      const img = make();
      img.decoding = 'sync';
      img.src = p;
      if (typeof img.decode === 'function') img.decode().catch(() => {});
    } catch { /* preload gagal -> GIF tetap dimuat saat tampil */ }
  }
  return paths.length;
};

## 6. Risks, tradeoffs & open questions

**Risiko teknis + mitigasi**
1. **`triggerEffect` disentuh** → risiko regresi Gojo/Hina. Mitigasi: jalur Yuji = early-return tepat setelah `onMilestone`, jalur lama tidak diubah; smoke test wajib mencakup Gojo/Hina/Sumi (langkah 11).
2. **GIF panjang (shimata 5070 ms)** → efek bisa terasa nyangkut; mitigasi: clamp 8000 ms + `clearFxIfCurrent` (pola Gojo) sudah dipakai.
3. **Nama file GIF pakai spasi** (`sukuna transform.gif`) → sama seperti Gojo (`ryoiki tenkai.gif`) yang sudah live; browser meng-encode otomatis. Jangan rename.
4. **Bar 20 slot di layar kecil** → slot `1.4vh` + `minHeight 6px`; cek 375px. Kalau kekecilan, ganti ke 10 slot × 2 jari (1 baris perubahan di `YujiCurseBar`) — tapi itu menyimpang dari desain "1 benar = 1 jari".
5. **6 opsi (Medium/Hard)**: burn 2 dari 5 opsi salah → sisa 4, bukan 50/50 literal. Desain mengasumsikan 4 opsi; diterima (catat di PR/commit).
6. **Finisher lintas-transisi**: kalau takeover timeout setelah 開 keluar, finisher TETAP aktif untuk soal berikutnya (sudah "dibayar"). Kalau user keluar quiz → `endQuizSession` membersihkan. Ini keputusan sadar.
7. **Suara bar/collapse memakai aset generik Gojo** (`playCurseTick`, `playCurseReady`, `playDomainCollapse`) → hemat kode; kalau user mau rasa Yuji khusus, tinggal ganti pemanggilan (titik tunggal di `triggerYuji`/`castTakeover`).

**Open questions (default sudah dipilih di plan; ganti kalau user bilang lain)**
- Setelah combo 3 (開), takeover lanjut sampai 30 dtk / salah, combo tidak bisa naik lagi (benar berikutnya = teknik streak). Alternatif: takeover langsung berakhir saat 開. **Default: lanjut.**
- Bar 指 digambar sebagai 20 slot bersegmen (bukan siluet jari literal). Iterasi visual menyusul kalau diminta.
- Urutan "ignite" kanji 開: versi plan = reveal gradasi api naik dari bawah (clip-path). Versi stroke-order (gambar guratan satu-satu dari data `public/strokes/`) = **follow-up opsional**: tambah `開` ke `needed` di `scripts/vendor-stroke-data.mjs`, jalankan `node scripts/vendor-stroke-data.mjs`, lalu muat via `loadStrokeData('開')`. Tidak masuk scope sekarang (YAGNI).
- `宿儺の器` tidak punya klip voice (teks doang) — sesuai desain; SFX `possessWhoosh` sebagai gantinya.
